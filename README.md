# qTexter

Небольшая утилита Windows для простых операций с текстом: сверху панель
инструментов, в центре текстовое поле, внизу — значки приложений. Клик по
значку копирует текст в буфер обмена, запускает приложение и (если у цели
задан `paste`) вставляет текст туда нажатием Ctrl+V.

Окно не сужается меньше ширины панели инструментов; эта же ширина —
начальная. Кнопка «⋮» открывает меню действий, значки приложений —
без подписей.

## Сборка

Требуется Go и MinGW-w64 (Fyne использует CGO). На этой машине уже есть
MSYS2 в `C:\msys64`:

```
build.bat
```

что эквивалентно

```
set PATH=C:\msys64\mingw64\bin;%PATH%
set CGO_ENABLED=1
go build -trimpath -ldflags "-s -w -H=windowsgui" -o qTexter.exe .
```

Значок приложения зашит в exe (`rsrc_windows_amd64.syso`, подхватывается
сборщиком автоматически) и в окно (`icon.png` через go:embed).
Перегенерировать: `go run ./cmd_genicon`, затем
`go run github.com/akavel/rsrc@latest -arch amd64 -ico icon.ico -o rsrc_windows_amd64.syso`.

## Панель инструментов

**Буфер обмена при запуске приложений** кладёт не только текст, но и
RTF-версию с текущим шрифтом и размером — Word и Outlook вставляют
текст в этом оформлении, Блокнот берёт обычный текст.
Кнопки «Копировать», «Вырезать» и «Копировать всё» кладут буфер в том
же формате (текст + RTF).

**Выделение.** Операции панелей применяются к выделенному фрагменту;
последнее выделение помнится даже если поле сбросило подсветку при
клике по кнопке. Позиция курсора сохраняется при заменах — текст
не «прыгает» к началу.


**«Действия»** — меню с операциями над текстом: ВЕРХНИЙ РЕГИСТР, нижний
регистр, Как в предложении, Обрезать пробелы, В одну строку, Убрать
пустые строки, Сортировать (по правилам русского языка), Уникальные,
Реверс, Копировать всё, Очистить. Операция применяется к выделенному
фрагменту, если он есть и встречается в тексте один раз, иначе — ко
всему тексту.

Шрифт поля по умолчанию — **Lucida Console**, размер — 12 пт. Кнопки
«−»/«+» меняют размер на 1 пт (пределы 8–28), клик по цифре между ними
открывает сетку размеров. Размер шрифта и размер окна сохраняются в
`settings.json` и восстанавливаются при следующем запуске.

Значки приложений без подписей: при наведении на значок (через пол
секунды) название приложения появляется подсказкой рядом с курсором.

## Панель приложений и apps.json

Список приложений лежит в `apps.json` рядом с exe (если каталог только
для чтения — в `%APPDATA%\qTexter\apps.json`), при первом запуске
создаётся автоматически с автодетектом установленных программ
(Word, Outlook — через реестр, Telegram — в т.ч. в `C:\Programs\Telegram`).
**F5** перечитывает конфиг без перезапуска.

Формат записи:

```json
{
  "name": "Google",
  "url": "https://www.google.com/search?q={text}",
  "color": "#4285F4",
  "icon": "search",
  "browser": "msedge"
}
```

| Поле      | Значение                                                                    |
|-----------|-----------------------------------------------------------------------------|
| `name`    | подпись кнопки                                                              |
| `exe`     | путь к программе (вместо `url`)                                             |
| `url`     | ссылка — открывается браузером по умолчанию                                 |
| `args`    | аргументы командной строки для `exe`                                        |
| `{text}`  | placeholder в `url`/`args` — заменяется на текст из поля (URL-encoded)     |
| `paste`   | послать Ctrl+V активному окну после запуска (по умолчанию `false`)          |
| `delayMs` | задержка перед Ctrl+V (по умолчанию 300)                                   |
| `icon`    | `search`/`translate`/`mail`/`doc`/`chat`/`globe` или путь к png/svg-файлу   |
| `color`   | цвет подложки значка `#RRGGBB`                                              |
| `browser` | браузер для `url`-целей: `chrome`, `msedge`, `firefox`, `brave`, `opera`, `vivaldi`, `yandex` или путь к exe; пусто — системный по умолчанию |
| `preKeys` | клавиши перед Ctrl+V: `tab`, `enter`, `space`, `esc`, `up`, `down`          |
| `waitClass` | класс окна цели, которого дождаться перед вставкой (`OpusApp` у Word, `Notepad` у Блокнота); ждём до 20 с, затем `delayMs` на доуточнение интерфейса |

Значения по умолчанию для Office и мессенджеров учитывают особенности
запуска: Word — `/q /w` (пустой документ без стартового экрана) и
`waitClass: "OpusApp"` (Ctrl+V уходит только после открытия окна
документа); Outlook — `/c ipm.note`, `preKeys: ["tab", "tab", "tab"]`
(фокус нового письма стоит в «Кому»; три Tab ведут в тело); Telegram —
автопаста в поле сообщения с `waitClass: "Telegram Desktop"`. Вставка
идёт в новое окно цели после того, как оно непрерывно удерживает фокус
0,3 с; если окно с заданным классом не появилось за 20 с, вставка
отменяется, чтобы Ctrl+V не ушёл в чужое окно. Если в системе Office со
сбойной активацией, «Мастер активации», выскакивающий поверх нового
окна Word/Outlook, закрывается автоматически до вставки.

## Настройки окна — settings.json

Рядом с exe (при недоступном каталоге — `%APPDATA%\qTexter`) хранится
`settings.json`: размер шрифта поля и размер окна. Создаётся и
обновляется автоматически; при отсутствии или повреждении применяются
значения по умолчанию (12 пт, окно по ширине панели).

Если `icon` не задан, для `exe`-целей значок извлекается из самого exe.

Для целей с `{text}` в команде (Google, Переводчик, Gmail) вставка не нужна:
текст передаётся самой ссылкой. Учтите, что очень длинный текст в URL может
обрезаться браузером (~2000 символов) — текст при этом всё равно остаётся
в буфере обмена.

## Заметки

- Автопаста посылается в активное окно: окно qTexter сворачивается перед
  запуском цели, но если цель открывается медленно — увеличьте `delayMs`.
- Telegram и VK открываются без автопасты (`paste` не задан): чат выбирает
  пользователь, текст уже в буфере — достаточно Ctrl+V.
